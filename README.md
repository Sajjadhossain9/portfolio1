# Sajjad Hossain Portfolio

## Add your background video

1. Create an `assets` folder in this repository.
2. Upload your video as `hero-video.mp4`.
3. Optional: upload a still image as `hero-poster.jpg` for fast initial loading.

Keep the video short (around 6–15 seconds), silent, compressed and under roughly 10 MB for good mobile performance.

The hero video is controlled by scroll position:
- scrolling down moves it forward;
- scrolling up moves it backward.

## Publish

In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**, then select `main` and `/(root)`.
